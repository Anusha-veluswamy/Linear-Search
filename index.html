5 · Think about it

Best case. Which position makes linear search finish fastest? How many comparisons?
Show answer

The target is at index 0 → only 1 comparison. Best case is O(1).

Worst case. Try "Last book" and "Not on shelf". How many comparisons does each take for n books?
Show answer

Both need n comparisons: every book gets checked. Worst case is O(n).

Pattern. If the target is at index k, how many comparisons happen?
Show answer

k + 1. Indices start at 0, so the book at index 3 is the 4th one checked.

Sorted? This shelf happens to be alphabetical. Does linear search use that fact?
Show answer

No. Linear search works on unsorted lists too (try Shuffle). Binary search is what takes advantage of sorted order.

Why -1? Why does the function return -1 when the book isn't found?
Show answer

-1 can never be a valid list index from range(len(arr)), so it safely means "not found".
